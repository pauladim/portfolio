# Paul's Portfolio

A modern, responsive portfolio website showcasing my skills, projects, and experience as a Full Stack Developer.

## Features

- Responsive design that works on all devices
- Modern UI with smooth animations and transitions
- Interactive circular text animation in the hero section
- Sections for About, Projects, and Contact
- Bootstrap-based responsive components
- Particle background effects
- Smooth scrolling navigation
- Form validation for contact form

## Technologies Used

- React 19
- Vite 7
- Bootstrap 5
- React Bootstrap
- CSS3

## Installation

1. Clone the repository:
```bash
git clone <repository-url>
```

2. Navigate to the project directory:
```bash
cd paul-portfolio
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm run dev
```

## Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build the project for production
- `npm run preview` - Preview the production build locally
- `npm run lint` - Lint the code

## Customization

To customize this portfolio:

1. Update the content in each section (About, Projects, Contact)
2. Modify the color scheme in the CSS files
3. Add your own projects to the Projects section
4. Update the contact information in the Contact section
5. Modify the particle effects in particles.js
